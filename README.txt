ALAM DRIVING INSTITUTE — WEBSITE
================================

WHAT'S INSIDE
- index.html       → the main one-page website (home)
- guidelines.html  → the Driving Guidelines page
- styles.css       → all styling (shared by both pages)
- script.js        → menu, animations, FAQ accordion
- images/          → logo + photos (compressed, fast on mobile)

IMPORTANT: Keep all files together in the SAME folder, exactly like this.
index.html must stay at the TOP level (not inside another folder),
or the site will show 404.

--------------------------------
HOW TO DEPLOY (GitHub → Vercel)
--------------------------------
1. Create a new repository on GitHub (e.g. "alam-driving-institute").
2. Upload ALL the files and the images folder into the repository
   (drag & drop on the GitHub website works). index.html must be
   in the root of the repo.
3. Go to vercel.com → Add New → Project → import that GitHub repo.
4. Framework Preset: choose "Other" (or leave it — it auto-detects
   a static site). No build command, no settings to change.
5. Click Deploy. Done — your site is live, no 404.
